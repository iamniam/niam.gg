# niam.gg

A tiny, old-fashioned personal homepage with a real RSS feed. No JavaScript, trackers, database, or framework.

## Editing from iPhone

Once GitHub Pages and Pages CMS are enabled, open https://app.pagescms.org, sign in with GitHub, select `iamniam/niam.gg`, and edit **Bio & links** or **Notes / RSS** visually. Pages CMS commits edits to this repository, and GitHub Pages publishes them.

## Hosting

GitHub Pages → deploy from `main` branch, root (`/`). Leave your existing `niam.gg` DNS unchanged until the new site is ready. Custom domain setup is a separate step.

## How it works

This is a plain HTML/CSS site rendered by GitHub Pages' built-in Jekyll processor. The one editable profile lives in `_data/profile.yml`; each note lives in `_posts/`. The `feed.xml` RSS is generated by Jekyll from the same notes, so nothing has to be edited twice. `.pages.yml` configures Pages CMS. Do not add a `.nojekyll` file, because Jekyll builds the notes and feed.
